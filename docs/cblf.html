6. Why the archived best scored what it scored

The reported 0.2778 is an unverified historical report; no submission-page receipt links that number to a file hash. What can be stated exactly follows from the official identity DTI = TP/(0.2·TP + 0.2·FP + 0.8·|G|), because FN = |G| − TP:

TP = d·(0.2·FP + 0.8·|G|)/(1 − 0.2·d) recall = TP/|G| ≥ 0.8·d/(1 − 0.2·d) (the FP = 0 case) d = 0.2778 → recall ≥ 0.2353 d = 0.4413 → recall ≥ 0.3872

So the archived file covered at least 23.5% of the hidden scored truth pixels within 300 m, and the current public leader at least 38.7%. Measured lineage: H33 is exactly D2.8 (44,090 px) minus 6,436 px within two pixels of the catalogue, with 0 pixels on the catalogue. Because the organizer confirmed that known USGS/INGENIOUS fault pixels are masked out of scoring, deleting near-catalogue mass is free, and its advantage is consistent with spending the same budget on strictly more useful cells. That is a metric mechanism, not proof of a causal leaderboard gain.
