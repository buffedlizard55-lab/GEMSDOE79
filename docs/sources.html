DD-PROBLEM
OFFICIAL SOURCE

DrivenData competition organizer

https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/ ↗

Review: read both chunks in full · 2026-10-22

  • Task: fault detection indicative of geothermal resources, not direct vent/reservoir discovery.
  • Initial test labels are expert-identified faults absent from the current public USGS database.
  • Provided numerical feature GeoTIFF is EPSG:32611 at 100 m resolution.
  • Distance-weighted TP is a maximum of p(x) times a triangular kernel over predictions around each truth pixel; FP uses distance to the truth; FN is truth mass minus weighted TP.
  • Triangular radius is 300 m; alpha is 0.2 and beta is 0.8.
  • Submission: single-layer float32 GeoTIFF, confidence values between 0 and 1, same CRS, resolution and bounds. Text says data outside bounds is null or NaN.

Limits: Page access does not authenticate the owner-mirrored data bytes. A local validator cannot prove remote portal acceptance.

USGS-GEODAWN
OFFICIAL SOURCE

U.S. Geological Survey data release

https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and ↗

Review: full scientific description and citation read · 2026-10-22

  • Aeroradiometric data inform surface geology and soil composition; aeromagnetic data inform subsurface structure and geology.
  • Area 2 nominal flight-line spacing is 400 m and tie-line spacing is 4000 m; grids at 100 m do not imply independent 100 m observations.
  • Magnetic processing includes tie-line levelling and micro-levelling; variable terrain clearance should be considered in interpretation.
  • GeoTIFF grids, CSV line data, flight-path shapefiles and processing reports are listed as release products.
  • Area 1 nominal height is targeted at 100 m over low relief and 150 m over mountains, with 200 m flight lines and 2,000 m tie lines; Area 2 targets 150/200 m with 400/4,000 m lines. Actual clearance can vary from the planned drape in steep terrain.
  • The official release listing includes contractor reports/readme, metadata CSV, flight-line CSVs, flight paths/outlines, and GeoTIFF geophysical grids.

Limits: Newly estimated magnetic-marker lags do not prove displacement or fault permeability. USGS release access is not independent confirmation that each mirrored derivative matches an original product. The release description warns about variable terrain clearance but does not establish here that every required per-sample altitude field is available; inspect official file metadata before using it.

    PRIMARY-TVERSKY-1977
    PRIMARY LITERATURE & ENCYCLOPEDIC REFERENCE

    https://en.wikipedia.org/wiki/Tversky_index ↗

    Review: read in full on 2026-10-22 · 2026-10-22

    • Defines asymmetric set similarity S(X, Y) = |X cap Y| / (|X cap Y| + alpha |X \ Y| + beta |Y \ X|); for alpha = 0.2, beta = 0.8, false negatives carry 4x the per-unit penalty of false positives.
