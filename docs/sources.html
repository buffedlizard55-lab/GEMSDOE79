DD-PROBLEM
OFFICIAL SOURCE

DrivenData competition organizer

https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/ ↗

Review: all chunks read in full on 2026-10-22 · 2026-10-22

  • Task: fault detection indicative of geothermal resources across the GeoDAWN NW Great Basin footprint, not direct vent/reservoir discovery.
  • Initial test labels are expert-identified faults absent from the current public USGS/INGENIOUS database.
  • Provided numerical feature GeoTIFF is EPSG:32611 at 100 m resolution; shape 3730 x 3292 matches sample_submission.tif.
  • Distance-weighted TP is a sum over ground-truth fault pixels of max_{x in B_R(g)} p(x) * k(||x - g||); FP sums p(x) * (1 - max_{g in B_R(x)} k(||x - g||)) over off-truth cells; FN is |G| - TP_w (verified against worked example TP_w=3.00, FP_w=1.89, FN_w=2.00 -> DTI=0.60).
  • Triangular kernel radius is R = 300 m (3 px at 100 m); asymmetric Tversky weights are alpha = 0.2 (FP) and beta = 0.8 (FN).
  • Submission specification: single-layer float32 GeoTIFF, confidence values between 0 and 1, identical CRS, resolution, and bounds; note live portal validator rejects NaN outside-footprint pixels ('Predicted values must be in range [0, 1]'), so all-finite 0.0 outside footprint is required.

Limits: Page access does not authenticate owner-mirrored feature bytes. A local validator cannot prove remote portal acceptance without an upload receipt.

Review: full scientific description and citation read on 2026-10-22 · 2026-10-22

  • Covers 51,857 km^2 (149,030 line-km) across NW Nevada and SE Oregon: Area 1 flight/tie spacing 200 m / 2000 m, Area 2 spacing 400 m / 4000 m; 100 m grids do not imply independent 100 m measurements.
