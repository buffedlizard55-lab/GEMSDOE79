How a file becomes eligible

  1. Place authorized competition data and establish a shared baseline.
  2. Run leakage canaries and buffered whole-segment hide-and-recover evaluation.
  3. Reject correlated/overlapping duplicates against every available registry raster.
  4. Write one-band float32 GeoTIFF; compare CRS, shape, transform, footprint and values.
  5. Record a run card and hash; let the separate selector choose whether to use a slot.
