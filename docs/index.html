Partial halo coverage alone does not prove every map fails; only saturated witnesses force it:

halo coverage = 100% of allowed cells ⇒ overlap = 100% for any nonempty dot set

The operative test is therefore the owner-adopted amendment-D2 chance-corrected overlap (ov−h)/(1−h) ≤ 0.70 against comparable sparse priors, with every raw reading published (IR-79-143). Dense corridor maps that flag this file under raw readings also flag withheld ground truth itself.
