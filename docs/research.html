What the family result pattern actually suggests

Every numerical family submission score in this section is an UNVERIFIED HISTORICAL REPORT from the repository ledger; none has an artifact-linked submission receipt, none is ORGANIZER-CONFIRMED, and none is HOLDOUT-DTI. The values motivate mechanistic questions only. Current holdout measurements are reported separately with evaluator, withheld-positive count, and 95% CI.

  1. Emission geometry appears to matter. The reported family values ≥ 0.23 are a sparse, isolated, binary dot field (≈37–44k dots, no 8-neighbour duplicates, pruned away from the catalogue). Continuous probability fields of the SAME parent surfaces score far lower (h19-5 continuous 0.1922 → dotted D2.8 0.2600). Reason: the official metric takes a max over the 300 m triangular kernel for TP but sums p(x)·(1−k) for FP — redundant nearby mass is pure FP cost. Isolated 1.0 dots at ≥300 m spacing are the near-optimal emission for a given ranking surface.
  2. H33 (0.2778, user-reported, unverified) is not a new model. Byte forensics in this repo show H33 ≡ D2.8 with the 6,436 dots within 200 m of the known catalogue deleted (44,090 → 37,654; 0 disagreements). Its gain is consistent with removing catalogue-echo dots whose marginal TP credit is low: hidden test faults are NEWLY mapped faults, so dots hugging known traces mostly re-find what is already mapped (scoring masks exact known pixels) while paying FP on the 1–2 px halo.
  3. The score ledger's UNVERIFIED HISTORICAL REPORTS for single-physics novel lanes (Euler depth, worm persistence, SGMC off-catalogue, basement step, supervised HGB, and lidar-scarp-only) are generally low relative to the highest reported family values. The apparent survivors are multi-evidence corroboration surfaces (h19-4/h19-5 "multiline-corroborated" lineage) — agreement of independent evidence may suppress each sensor's characteristic false positives. Because the file/score pairings are not receipt-authenticated, this is a research pattern, not a verified leaderboard result.
  4. This repo's own holdout instrument is gems57-pooled-hide-v2, with whole-component spatial holdouts and a 3-px emission design. The E1 post-stop diagnostic and current G79B candidate/control measurements are negative; their seed-specific HOLDOUT-DTI, withheld-positive counts and 95% CIs are recorded in evidence/post_stop_diagnostic.json, evidence/run_card.json, and evidence/holdout_g79b_seed20.json / evidence/holdout_g79b_seed30.json. Do not substitute the family leaderboard ledger for holdout evidence. The bar for a future lane is beating the fold-fair H33 control on the same instrument — not a leaderboard projection.

Decision

Implement Rank 1 (G79B-SCARP-DIPOLE-GEOAND) exactly as preregistered in registry/preregistration_g79b.json. No fitted model, no catalogue-based features (catalogue is used only as a placement exclusion mask, derived from visible faults only inside each holdout fold), no prior prediction raster enters the surface. Emission: 37,654 isolated binary dots, min spacing 3 px, placement excluded within 2 px of the (visible) catalogue — the H33 emission lesson applied fold-fairly to every placed control arm too.

Promotion gate (fixed in advance): pooled HOLDOUT-DTI must beat the fold-fair H33 control and every matched control (lidar-only, geo-only, uniform) with paired 95% CI lower bound > 0 on both seeds 20 and 30. Anything less = verdict negative, TIF still generated and clearly labelled DO NOT SUBMIT. No leaderboard score is projected from holdout.

No new external data is required: all inputs are the SHA-256-pinned cached stack restored this session (registry/data_manifest.json, 13/13 verified). The free official sources behind them are USGS GeoDAWN (https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and), USGS 3DEP 1 m DEMs (via the competition's 1m_DEM_links.csv), and Census TIGER roads — all already mirrored as pinned derivatives; no new download is on the critical path.

Trusted-source boundary

  • DrivenData problem description was read in full: this is fault mapping, not direct detection of vents, reservoir temperature, productive permeability, or commercially viable wells. Existing labels are incomplete; new expert-labelled faults form test data.
  • USGS GeoDAWN data release explicitly identifies aeromagnetics with subsurface geology/structure and aeroradiometrics with surface geology/soil composition. It also documents differing survey specifications, tie-line levelling and terrain-clearance variation. Those are confounders, not proofs of a new fault.
  • Official organizer reference implementation confirms a train/predict baseline is available. It does not validate this new physical hypothesis or any expected improvement.

The displacement interpretation is a testable hypothesis, not an assertion that every detected lag is a fault. Rejection by hide-and-recover, leakage, or literal novelty gates is an equally valid deliverable. No weekly slot is used.

Post-stop availability clarification (software/source review, 2026-10-21)

The restored external radiometric file is a four-band uint8 derivative, labelled K, Th, U and TC on the reference grid, not a newly authenticated calibrated USGS measurement product. Rank-based profile analysis could use its spatial pattern, but quantitative concentrations, ratios or physical error bars are not justified by those bytes. Original USGS GeoDAWN grids/reports are the free official source needed to establish units and processing; the release was reviewed, but no new direct binary download was verified in this sandbox. This clarification does not change the immutable E1 preregistration or revive E1.
