Session 0a202578: H33, the leaderboard, and the G79-FSC result

1. Why GEMSDOE32 H33 scored 0.2778, and can we beat it?

Evidence classes. The 0.2778 for h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros is USER-REPORTED. On 2026-10-21 the public leaderboard showed the same number (0.2778) at rank 48. That match does not prove which file or account earned it (knowledge/official_sources.json, entry DD-LEADERBOARD). On 2026-10-22 the public leaderboard showed #1 xiaofanhu 0.4413, #2 0.3904 and #3 0.3894 (PUBLIC LEADERBOARD OBSERVATION). The value 0.3195 in the prompt is not the current top score.

What H33 is. H33 is a 37,654-dot binary map. It is D2.8 (44,090 dots) with the 6,436 dots within 2 px of a mapped fault removed. We re-measured this from the pinned bytes; see knowledge/h33_review_e4a4422d.md. Here is how the organizer's metric works:

  • Each truth pixel gets the maximum nearby kernel credit.
  • Every predicted pixel adds false-positive mass.

With T = weighted TP, F = weighted FP and G = scored truth pixels:

DTI = T / (0.2 T + 0.2 F + 0.8 G)

A dot is worth adding only if its credit exceeds 0.2 × DTI. So sparse, well-placed dots beat dense maps. H33's 0.2778 is consistent with good per-dot efficiency. That explanation follows from the metric; it is not proof of what the hidden labels contain.

Can we beat it? On this project's spatially blocked holdout, the archived G79-THVC lane scores HOLDOUT-DTI 0.1905 / 0.1944. The H33 fold-fair analogue on the same split scores 0.0961 / 0.0989, so THVC is about 2× better. Both pairs of numbers are frozen, from evaluator gems57-pooled-hide-v2. This session's G79-FSC scores 0.1406–0.1580, which also beats the H33 analogue (point estimates only; no paired interval vs H33 was computed). HOLDOUT-DTI hides already-mapped faults, so these numbers cannot be converted into leaderboard scores. Whether any of these files would beat 0.2778 publicly is unknown until one is submitted.

2. G79-FSC: hypothesis, experiments, result

  • Hypothesis H1: hidden Basin-and-Range faults are sub-parallel to the local mapped fault fabric. Physical edges whose strike agrees with that fabric are more often faults. The edges come from detrended topography, isostatic gravity, RTP magnetics and the LiDAR scarp strike band. The fabric is the structure tensor of the visible catalogue.
  • Mechanism: fault populations in an extensional stress field share a strike set. Unmapped splays and buried continuations inherit that strike.
  • Named non-fault mimics: pluvial Lake Lahontan shorelines and alluvial-fan toes, which parallel range fronts. Also NNE dikes in magnetics.
  • Preregistration: registry/preregistration_g79_fsc.json, commit 49d2383, made before any feature or score existed. Amendment A1, registry/preregistration_g79_fsc_amendment_A1.json, commit fedd6c7. A1 was registered after the seed-20 result was seen and before seed 30 existed. That is one disclosed extra look at the holdout.

Verdict: NEGATIVE.

  • Every FSC arm is 0.036–0.050 below THVC on both seeds. The preregistered promotion gate requires beating THVC on both seeds.
  • The fabric idea carries some real but small signal: it is significant on one of the two seeds.
  • The model's gain is dominated by smooth regional fields: surface conductance, earthquake density, geodetic strain. In other words, it learns where fault-rich regions are more than where a missing strand lies.
  • At 45k dots it pays FP mass 41.6k for TP 2.5k. THVC pays 34.7k for 3.2k (seed 20).
  • Novelty (amendment D-2, 1,216 comparable registry rasters, 0 invalid; this repository's own archived TIFFs included):
  • The surface before placement is a duplicate of 33 prior dot fields: chance-corrected overlap > 0.70, max 0.887.
  • The final dots clear every informative raster: max chance-corrected overlap 0.590, max ρ 0.110. They are still flagged against 4 rasters that are positive on every cell. Under D-2's saturated branch, any non-empty file fails against those 4 (IR-79-195).
  • The published GeoTIFF is therefore research-only and labelled DO-NOT-SUBMIT. It fails gate G1 (holdout), gate G4 (surface novelty) and gate G5 (saturated-branch novelty).

3. What this teaches

  1. Placement efficiency dominates. The incumbent's crack-tip continuation plus kernel-cover placement extracts more TP per dot than a classifier plus top-K NMS.
  2. Orientation agreement alone does not localize faults at 100 m. Regional context explains most of the classifier's skill.
  3. The budget rule (≤ 3 experiments) stopped a fourth try. This was the right call because each extra look at the same holdout inflates apparent gains.

4. Limitations

  • The holdout hides catalogue faults. The organizer scores new expert-labelled faults, so gains may not transfer.
  • The two seeds share geography and catalogue, so they are not independent datasets.
  • No paired CI against THVC is possible because THVC's fold predictions were not cached.
  • Novelty uses amendment D-2. The literal overlap rule is 1.0 for every non-empty file (evidence/universal_overlap_certificate.json), so it carries no information. The literal reading is still printed.
  • Structural blocker: D-2's saturated branch has the same flaw (IR-79-195). Until the owner makes a prospective decision ("D-3") about rasters that are positive everywhere, no file from any lane can pass every gate.

Supplementary novelty (post-merge). The completed scans could not include the parallel CJX and DZD TIFFs, which reached main later. The same shared D-2 tool finds 0 duplicates against both. The worst chance-corrected overlap is 0.369 on the surface and 0.241 on the dots, both against CJX (evidence/fsc/novelty_supplement_artifacts.json).

Hypothesis 1 (G79-SFGC): Signed Scarp-Facing Polarity & Hangwall-Basin Gravity Concordance + Flank-Decontaminated Dinkelbach Allocation

  • Geological & Geophysical Mechanism:
  • In src/gems79/thvc_features.py line 589, canonical G79-THVC computed np.abs(lid_up - lid_down) / (lid_up + lid_down + 5.0) and discarded Band 11 (strike) of lidar_scarp_features_u8.tif, destroying the sign of topographic scarp facing relative to regional piedmont slope.
  • Across Great Basin piedmonts, antithetic normal fault scarps (upface_max > downface_max) face up-slope against the alluvial-fan gradient (grad(det_elev)), forming graben counter-scarps that pond sheetwash. Wave-cut pluvial shorelines and fluvial terrace risers can never face up-slope against the basinward hydraulic gradient; they strictly face down-slope (downface_max >> upface_max) along elevation contours (|grad(det_elev) x t_strike| approx 0).
  • Conversely, synthetic range-front and piedmont splay scarps (downface_max > upface_max) drop Cenozoic low-density basin fill on their down-facing hanging wall, requiring signed polarity concordance n_downface . (-grad_H(iso_grav_anom)) > 0 across 300-900 m cross-strike profiles, whereas wave-cut shorelines etched into uniform fan gravel exhibit zero basement-density polarity step.
  • Simultaneously, G79-SFGC repairs the two verified loss/training mismatches in src/gems79/thvc_model.py (IR-79-176): (a) excluding 0 < d_vis <= 3.0 px (100-300 m) visible-fault scarp flanks from y = 0 negative sampling (sim_neg_pool = footprint & (d_vis_px > 3.0)), and (b) replacing fixed lambda_fp = 0.0022 with exact outer Dinkelbach fractional updates lambda(theta_t) = 0.2 * theta_t / (1.0 - 0.2 * theta_t) under alpha = 0.2, beta = 0.8.
  • Why Missing from USGS/INGENIOUS Catalogue: USGS hazard traces simplify multi-strand piedmont fault zones into a single master range-front polyline (10.5066/P9BCVRCK), omitting 100-800 m outboard synthetic/antithetic graben strands that DrivenData Staff (thread 11536/2) confirmed count as new faults.
  • Named Non-Fault Mimic & Falsification Test: Pleistocene Lake Lahontan / Bonneville regressive shoreline benches (1,200-1,335 m elevation bands) and Humboldt/Truckee fluvial terrace risers. Falsified if signed uphill-facing index (lid_up - lid_down) / (lid_up + lid_down + 5.0) and gravity-concordant synthetic index fail to reduce false-positive density along flat-contour shoreline elevations on withheld quadrants.
  • Difference from All Prior Lanes: Distinct from G79-THVC (which took abs(lid_up - lid_down) and ignored strike), G79-BLC (elevation-band shoreline z-scoring without signed upface_max - downface_max or signed -grad(iso_grav_anom) polarity), and H83-GVCD (which lacked GDR-1391 2-m probe/sinter features and signed LiDAR facing).

Hypothesis 2 (G79-UGBP): Up-Gradient Kinetic Geothermometer Disequilibrium Back-Projection

  • Geological & Geochemical Mechanism:
  • data/raw/external/gdr_wellspring_in_footprint.csv (27,092 rows; 8,718 measured outflow temperatures temp_c; 827 fluid-chemistry records carrying paired quartz geothermquartz_c and Na-K-Ca cation geothermcat_c geothermometers) encodes reaction-transport kinetics that both G79-THVC and H79-FNHR ignored by placing isotropic Gaussian kernels directly at the well/spring coordinates.
  • Per Fournier (1977) and Giggenbach (1988), dissolved silica re-equilibrates by conductive cooling and chalcedony/amorphous-silica precipitation over days-to-months during shallow lateral flow through alluvial aquifers, whereas Na-K-Ca cation ratios re-equilibrate orders of magnitude more slowly, preserving deep fault-conduit reservoir temperatures (150-240 C).
  • Therefore, high T_Qtz with small disequilibrium dT_diseq = T_Cat - T_Qtz <= 15 C marks proximal vertical fault-conduit upflow beneath the sample site, whereas elevated T_Cat >= 110 C paired with large disequilibrium dT_diseq = T_Cat - T_Qtz >= 25 C and large conductive drop T_Qtz - temp_c >= 40 C diagnoses a distal lateral alluvial outflow plume fed by an unmapped blind fault located 1-8 km up-gradient along +grad_H(det_elev) at the first crossed iso_grav_anom_hg / TMI_up150 basement step.
  • Why Missing from USGS/INGENIOUS Catalogue: Blind range-front step-over and intra-basin feeder faults beneath permeable piedmont fans lack surface coseismic scarps (M > 6 trenching targets) and are masked by lateral shallow groundwater dispersion.
  • Named Non-Fault Mimic & Falsification Test: Non-fault lateral thermal groundwater plumes in permeable alluvial-fan channels down-slope of range fronts, plus agricultural irrigation return wells. Falsified if up-gradient anisotropic advection onto iso_grav_anom_hg ridges does not improve fold-fair HOLDOUT-DTI over isotropic springhead Gaussians (gdr_geotherm_qtz_1800m).
  • Difference from All Prior Lanes: Every prior thermal lane (G79-THVC, H79-FNHR, G79-HFR, GEMSDOE32 heatfield) placed radially symmetric kernels centered on surface thermal points or required unacquired USGS heat-flow residuals; none used T_Cat - T_Qtz kinetic disequilibrium or up-gradient topographic advection.

Hypothesis 3 (G79-MDSC): Multi-Altitude Magnetic Upward-Continuation Structural-Index Depth Screening

  • Geological & Potential-Field Mechanism:
  • Combines geodawn_extensions_u8.tif Band 4 (TMI_up150, upward-continued at +150 m) with training_features.tif Bands 2 (rtp), 3 (tmi_hg), 9 (tmi_vg), and 14 (tmi), plus tiled 2D FFT upward continuation of rtp to altitudes dz in {150, 300, 600} m.
  • Under potential-field continuation theory (Spector & Grant 1970; Reid et al. 1990), horizontal-gradient amplitude decays across altitude step dz according to ||grad_H M(z0 + dz)|| / ||grad_H M(z0)|| = (z_top / (z_top + dz))^(N + 1), where structural index N approx 0 characterizes a finite-throw faulted step/contact, N approx 1 a thin dike/sill edge, and N >= 2 localized surficial magnetic float/pipes.
  • Solving jointly across dz in {150, 300, 600} m isolates shallow sub-alluvial Quaternary fault contacts (z_top in [50, 400] m, N in [0.0, 0.6]) while suppressing both high-amplitude surficial basaltic boulder/talus noise (z_top < 30 m, N > 1.5) and broad deep plutonic roofs (z_top > 1,800 m) where surface scarps do not propagate.
  • Why Missing from USGS/INGENIOUS Catalogue: Faults offsetting Miocene-Pliocene volcanic units beneath 50-400 m of Quaternary basin fill leave no surface photogeologic scarp in legacy USGS compilation maps (10.5066/P9BCVRCK).
  • Named Non-Fault Mimic & Falsification Test: Unfaulted basaltic lava-flow lobe margins, volcanic talus aprons, and deep Mesozoic granitoid pluton boundaries. Falsified if restricting potential-field ridge features to z_top in [50, 400] m and N <= 0.6 fails to reduce false positives on non-faulted volcanic tablelands in withheld quadrants.
  • Difference from All Prior Lanes: Distinct from H80-DRAPE (IR-79-150, which applied an E-W azimuth notch |f_x| <= 0.02 and hurt holdout), G79-CJX (2D ridge-junction geometry without multi-altitude vertical attenuation), and H79-MCT (tilt angle without structural-index separation).

Hypothesis 4 (G79-PSDC): Playa-Subcrop Diagenetic Cementation & Phreatic Evaporite-Redox Barrier Lineaments

  • Geological & Hydrogeochemical Mechanism:
  • Nearly a fifth of the Basin-and-Range basin-interior footprint consists of zero-relief Pleistocene pluvial playas and alkali flats (chi_playa_raised == 1, det_elev_slope < p20) where LiDAR and 10-m DEM slope/scarp detectors drop to zero sensitivity, causing tree ensembles to starve basin floors of predictions or revert to noisy gravity peaks.
  • In Great Basin playas (e.g., Dixie Valley, Columbus Marsh, Edwards Creek, Black Rock), active intrabasinal faults act as low-permeability diagenetic clay/silica/calcite smear barriers across shallow phreatic flow, forcing linear alignments of cold/warm seeps (gdr_wellspring_in_footprint.csv spring_features), phreatic tufa/evaporite mounds, and redox-controlled uranium-over-thorium (U/Th) roll-front enrichment (geodawn_rad_u8.tif U, Th and geodawn_extensions_u8.tif UTh) collinear with iso_grav_anom_vg zero-crossings (cond_surf conductive clay boundaries).
  • Anthropogenic playa causeways, railroad grades, and drainage canals are explicitly vetoed using tiger_road_distance_m.tif (road_d <= 200 m).
  • Why Missing from USGS/INGENIOUS Catalogue: Seasonal playa flooding, halite/clay deflation, and lacustrine silt aggradation erase coseismic surface scarps within centuries, hiding active intra-playa transfer faults from paleoseismic compilation maps.
  • Named Non-Fault Mimic & Falsification Test: Eolian playa-margin lunette dunes, giant desiccation polygons, and raised gravel/railroad causeways across alkali flats. Falsified if U/Th + spring-line + iso_grav_anom_vg collinearity inside chi_playa_raised masks (road_d > 200 m) fails to improve recall on basin-interior withheld segments.
  • Difference from All Prior Lanes: G79-RSS explicitly down-weighted radiometric contrast in alluvial basins; G79-THVC used K/Th sericitic/argillic alteration globally rather than playa-specific U/Th phreatic redox-barrier + iso_grav_anom_vg zero-crossing collinearity.

Hypothesis 5 (G79-MCST): GPS Velocity-Derived Principal-Strain Mohr-Coulomb Dilation & Slip Tendency on Buried Contacts

  • Geological & Geomechanical Mechanism:
  • training_features.tif provides only rotationally invariant scalar strain-rate summaries (geod_2ndinv, geod_shearrate, geod_dilaterate, Bands 4, 7, 8), which omit the principal extension azimuth phi_ext(x)! Without phi_ext(x), a model cannot tell whether a buried geophysical contact striking at azimuth theta(x) is optimally oriented for Holocene normal/transtensional opening (theta(x) approx phi_ext(x) +- 90 deg) or locked in compression/null-slip (theta(x) approx phi_ext(x)).
