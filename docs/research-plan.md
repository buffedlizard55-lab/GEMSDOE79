# Research plan — ranked, testable candidates

**State:** proposals only. None has been computed or evaluated in a spatial holdout because this checkout has no input rasters, labels, cached feature stack, or common evaluator. Rankings are qualitative scientific/engineering priors, not measured DTI gains. No weekly submission should be spent on these proposals without passing the preregistered holdout gate.

### Relative ranking is not a score

The ranking reflects hypothesized mechanisms, ability to use the available competition stack, and engineering cost—not DTI projections, holdout results, or organizer scores. Candidate 1 is the only proposed first experiment because its core variables are identified in the official task description and it avoids requiring unverified external data. Its feature-by-feature leakage canaries and holdout evaluation are **blocked**, not passed.

## External source availability gate

The USGS GeoDAWN release is a verified, official public data release. USGS states that it includes magnetic and radiometric grids and line data, GeoTIFF products, and is marked CC0. This confirms a source catalog entry and stated license, but **does not confirm that a specific grid has been downloaded, that it covers the training footprint, that its license terms meet the competition rules in context, or that it aligns pixel-for-pixel**. Candidate 3 is therefore conditional, not validated. [USGS release](https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and) · [ScienceBase file catalog](https://www.sciencebase.gov/catalog/item/657e1d85d34e23d3533209f7?format=json) · [Competition external-data rule summary](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/).

Candidate 4's specific external source, if needed, is the free official [USGS Earthquake Catalog / ComCat search API](https://earthquake.usgs.gov/fdsnws/event/1/). Its availability as an official service is not equivalent to adequate local focal-mechanism coverage; coverage must be queried and summarized before it is considered viable. Candidate 4 can first be tested with the supplied earthquake-density band and does not depend on external data for that initial ablation.

## Preregistered test sequence (when shared data/tools exist)

1. Verify feature-layer metadata and all masks against the official training/sample rasters. Freeze the exact version/hash of the stack and evaluator. Do not infer layer order from a filename.
2. Establish an incumbent holdout baseline. Withhold complete fault segments and a buffer; compute all catalogue-dependent features from visible faults only; mask visible traces pixel-exactly. Use pooled distance-weighted Tversky at alpha 0.2, beta 0.8, 300 m triangular support. Report bootstrap 95% CI over withheld segments/folds and the number of withheld positive segments/pixels (unambiguously defined).
3. Leakage canary: evaluate each individual input feature alone using the identical hidden-segment split. Any AUC >0.90 is treated as leakage pending documented explanation; this does not replace direct inspection for rasterization/spatial leakage.
4. Test candidate 1 as one preregistered feature family against the same folds and matched emission budget. No tuning on held-out results. Compare to incumbent; do not proceed to a live slot unless the improvement exceeds uncertainty and duplicate gate passes.
5. Before candidate and final dot placement, compare rank correlation and 3-pixel overlap against every available registry raster. Record all compared registry hashes. Missing registry rasters means the duplicate gate is **unverified** and blocks promotion.
6. Have the shared writer create the candidate, validate exact raster format and scores, write a run card, and record SHA-256. Promotion is a separate decision and uses the live page's current weekly cap.

## Method-lane boundary

This repository started empty, so there is no checked-in prior “single method paragraph,” cached stack, evaluator, or writer to inherit. This plan proposes **one first lane only**: candidate 1, the multi-scale conductivity-base / gravity edge coincidence conditioned on strain-tensor coherence. Other rows are backups for later experiments and must not be blended into the first test. Since the existing user-supplied GEMSDOE results include many geophysics/structure and morphology methods, novelty is only asserted relative to this empty checkout and the precise transform proposal—not relative to every artifact on every GEMSDOE site. Registry-raster comparisons are required to resolve duplication empirically.
