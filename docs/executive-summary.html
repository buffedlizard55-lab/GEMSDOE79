How to submit a future promoted file

  1. Run .venv/bin/python scripts/submission_status.py. Upload only if it prints OK TO SUBMIT: YES and exits with code 0.
  2. Check that your submissions page shows a free weekly slot. The official rules allow up to three per week.
  3. Download the promoted .tif, or the ZIP holding exactly that one TIFF, from the top of the home page. Check its SHA-256 against the run card.
  4. Choose the file in "File to submit", paste the card's comment of 140 characters or fewer, and submit.
  5. Record the public score. Only that makes a number ORGANIZER-CONFIRMED for the file.

Account-side conditions the project cannot verify

  • A free weekly slot must be shown on your DrivenData submission page (the official rules allow up to three submissions per week).
  • You must be a registered, eligible participant who accepted the competition rules.

Why the earlier "values must be in range [0, 1]" rejection cannot recur

The shared writer refuses NaN, ±Inf, sentinels and anything outside [0, 1], and never clips silently. It then reopens the written TIFF and checks:

  • values are finite everywhere;
  • min ≥ 0 and max ≤ 1;
  • CRS, shape and transform match the sample;
  • the ZIP holds identical bytes.

This research file contains only the values 0.0 and 1.0.
