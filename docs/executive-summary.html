How to submit (5 steps)

  1. Check your slot. Open the official submissions page while signed in. The official rules allow up to three submissions per week. If no slot is free, wait; do not delete earlier entries.
  2. Download. Use the green button above for the .tif, or the ZIP, which contains exactly that one TIFF. Optional: check the SHA-256 with sha256sum (macOS: shasum -a 256). It must equal the value above.
  3. Upload. On the submissions page choose the file in “File to submit”.
  4. Describe it. Paste the comment shown above (99/140 characters). The file name already carries the unique submission name.
  5. Record the receipt. Note the public score and the time. That score, and only that, becomes ORGANIZER-CONFIRMED for this SHA-256.

How this file avoids the known “[0, 1]” rejection

The shared writer refuses NaN, ±Inf, sentinels and anything outside [0, 1]; it never clips silently. It then reopens the written TIFF and checks finiteness everywhere, min ≥ 0, max ≤ 1, CRS/shape/transform identical to the sample, and a ZIP holding exactly the same bytes. This file contains only 0.0 and 1.0, with 0 positive pixels on catalogue faults or outside the footprint.

Limitations

  • Distribution shift. Holdout withholds mapped faults; the organizer scores expert-found faults absent from the map. Median dot-to-catalogue distance here is 671 m vs H33's 1.96 km.
  • Proxy, not projection. This file has no ORGANIZER-CONFIRMED score until you upload it.
  • Uniqueness scope. Public sibling-repository rasters were checked, not every file other participants uploaded.
  • Portfolio caution (IR-79-122). The cross-repository audit (post_index_sibling_audit_20261022.json) found earlier sibling candidates that overlap each other heavily; never spend two weekly slots on near-duplicate portfolio files. This CONJ file's own overlaps are measured in the D-2 audit above.
  • Outside-footprint convention (IR-79-69). The official competition page (“Submission format”, drivendata.org/competitions/306/competition-doe-gems/page/967/) says data outside the bounds “is null or nan”, and the official sample uses NaN there; the official reference notebook writes finite values. This file follows the team all-finite policy (0.0 outside), which the shared writer enforces; portal acceptance of either convention is only proven by a successful upload.
  • One slot, your call. Promotion means every automated preregistered gate passed; spending a weekly slot remains your decision on the official page.
