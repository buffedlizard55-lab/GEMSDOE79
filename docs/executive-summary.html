How to submit (5 steps)

  1. Check your slot. Open the official submissions page while signed in. The official rules allow up to three submissions per week. If no slot is free, wait; do not delete earlier entries.
  2. Download. Use the green button above for the .tif, or the ZIP, which contains exactly that one TIFF. Optional: check the SHA-256 with sha256sum (macOS: shasum -a 256). It must equal the value above.
  3. Upload. On the submissions page choose the file in “File to submit”.
  4. Describe it. Paste the comment shown above. The file name already carries the unique submission name.
  5. Record the receipt. Note the public score and the time. That score, and only that, becomes ORGANIZER-CONFIRMED for this SHA-256. Add it to registry/score_ledger.csv in a later session.

How this file avoids the known range error locally

The shared writer refuses NaN, ±Inf, sentinels and anything outside [0, 1]; it never clips silently. It then reopens the written TIFF and checks:

  • finite values everywhere, including outside the footprint;
  • min ≥ 0 and max ≤ 1;
  • CRS, shape and transform identical to the sample;
  • a ZIP that holds exactly the same bytes.

This file contains only the values 0.0 and 1.0.

Limitations

  • Distribution shift. The holdout withholds mapped faults, while the organizer scores expert-found faults that are absent from the map. This lane deliberately uses no distance-to-mapped-fault input, so it cannot exploit catalogue clustering — and cannot be credited for it either.
  • Thin margin. Candidate minus H33-control HOLDOUT-DTI is positive on both seeds, but the paired 95 % intervals include zero. Treat the holdout as parity-or-better, not as proof this file outscores H33's lineage live.
  • Proxy, not projection. This file has no ORGANIZER-CONFIRMED score until you upload it.
  • Uniqueness scope. The 992 public sibling-repository rasters were checked, not every file other participants have uploaded.
  • Dot definition. The registry comparison uses budget-matched dots (Amendment D-1), chance-corrected excess overlap (Amendment D-2) and budget-comparability for that statistic (Amendment D-3, calibrated on lineage-distinct family lanes), because the literal definitions flag even uniform-random maps as duplicates of space-filling probes. The literal readings are published in full in the evidence, with the amendment texts and reversal clause in the reports.
